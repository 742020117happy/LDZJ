# RL 核验修复记录：防止操作日志占满磁盘

## 核验（2026-10-25）

日志写盘点全览：
- 中心日志：Debug_DB/软件操作日志_yyyyMMdd.log（T80 治理：总量 500MB→100MB，仅按大小）
- **8 个模块分文件：移动底盘.log/机械臂.log/左精扫消息.log/巡检过程信息.log/语音报警.log/远程IO.log/系统信息.log——无限追加，无任何治理** ← 磁盘占满主风险
- 风险场景：现场长期运行，模块文件与中心日志无限累积

## 修复（统一治理增强）

1. 中心日志：按天保留（默认 7 天，当天保护）+ 总量阈值（默认 100MB，T80 原 500MB 过高）
2. 模块分文件：单文件 >20MB 自动删除（各 Write_*_List 下次追加自动重建，无长句柄风险）
3. *.tmp 残留清理（D-009 原子写盘引入的临时文件兜底）
4. 配置化：Log_MaxDays（1-365，默认 7）/ Log_MaxMB（10-10240，默认 100）——三份配置已同步
5. 60s 节流检查保持；清理动作写当天中心日志留痕

## 编译

MSBuild 0 错误。

## 回归

- 正常写入路径不变；治理仅删除超限/过期文件
- 当天中心日志永不删除；模块文件删除后自动重建
