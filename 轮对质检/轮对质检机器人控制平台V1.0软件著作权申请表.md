## 软件主要功能

本软件是面向动车组轮对自动化质检场景的上位机控制软件，主要功能包括：

1. **多设备协同控制**：通过 Modbus TCP/RTU、HTTP REST、UDP/TCP 等协议控制 AMR 底盘、六轴机械臂、结构光精扫相机、远程 IO 站与语音播报器；
2. **自动质检流程编排**：接收 WEB 工作站下发的巡检任务指令，自动完成地图切换、位姿初始化、脱桩、逐工位走行、机械臂轨迹拍照、精扫图像采集、自动回充的全流程作业；
3. **双工位采集管理**：支持单工位与双工位巡检，双工位共用走行线逐点归属执行，采集信息随工位实时切换，保证图像采集指令、文件名、数据库记录与工位一致；
4. **图像采集协议实现**：实现 START/CHANGE/PHOTO/FINISH 采集指令协议，合成标准 11 段原始图像文件名，PHOTO 超时自动重发机制；
5. **安全防护机制**：导航定位失败双阈值判定（距离 1.5m/角度 10°）防止机械臂碰撞；设备断连/相机故障/机械臂错误实时报警；三色灯与语音分级报警联动；
6. **状态监控与上报**：以 500ms 频率响应 WEB 工作站状态查询（中文 Key 全量 JSON），采集数据入库，关键时间点上报 EMIS 系统。

## 软件技术特点

1. **三层解耦架构**：界面层/业务层/通讯层严格分离，通讯层零业务耦合零协议解析，层级间仅信号槽交互；
2. **多线程并发模型**：通讯层线程在业务层创建、业务层线程在界面层创建，QReadWriteLock 读写锁协议保障跨线程数据一致性；
3. **协议健壮性**：指令字段严格校验（禁空格/分隔符）、TCP 粘包处理、校验码幂等去重、写失败指数退避重试、断线自动重连；
4. **实时性能优化**：10ms 系统扫描+UI 变化检测降频、相机画面 cacheKey 帧检测、锁外重解码防 GUI 阻塞；
5. **运维友好**：统一日志中心（等级过滤/脱敏/限流/磁盘保留策略）、配置中心化管理、报警码体系。
