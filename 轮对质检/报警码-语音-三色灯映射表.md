# 报警码 — 语音报警条目 — IO 三色灯 映射表

> 生成日期: 2026-10-25
> 用途: 统一报警码命名，固化 报警码 ↔ 语音条目(PA001-PA025) ↔ 三色灯(红/黄/绿) 映射关系。
> 实现: `Robot_App_Widget.cpp` Status_Light_Voice_Scan（状态机）+ Work_Remote Voice_Event（事件）+ 手动按钮事件。

---

## 一、分级定义

| 级别 | 灯色 | 含义 | 处置 |
|------|------|------|------|
| 0 | 绿 | 正常静止 | 无动作 |
| 1 | 黄 | 警告/运行中（需注意但非故障） | 播报提示一次（档位变化时） |
| 2 | 红 | 报警/故障（需人工处理） | 播报告警一次（档位变化时） |

**三色灯互斥**：置位目标灯前自动关闭另两路（IO 侧 Set_Alarm_* 保证，T46）。

## 三、判定优先级（状态机）

```
红档判定（自上而下，命中即定）：
  A01 急停 → A02 断连 → A05 相机故障 → A03 机械臂错误 → A04 任务失败
黄档判定：
  A11 电量 → A12 定位丢失 → A13 充电故障 → A14 障碍 → A15 底盘警告
  → A16 暂停 → A17 巡检运行 → A18 机械臂运行
绿档：无上述任何条件
```

**防抖**：档位未变不动作（`m_Last_Light_Level`）；语音每档位只播一次。
