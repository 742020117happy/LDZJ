# 轮对质检机器人控制平台 V1.0 设计说明书

> 版本：V1.0　日期：2026-10-28
> 软件全称：轮对质检机器人控制平台　简称：Robot_App
> 开发语言：C++　技术栈：Qt 5.12.1 + VS2015（msvc2015_64）
> 运行环境：Windows 10 工控机（研华 MIC-770）

## 1. 软件概述

轮对质检机器人控制平台是面向动车组轮对自动化质检场景的上位机控制软件，部署于检修车间工控机，
通过 Modbus TCP/RTU、HTTP REST、UDP/TCP 等协议协同控制 AMR 底盘、六轴机械臂（CGXi）、
结构光精扫相机、远程 IO 站与语音播报器等设备，接收 WEB 工作站下发的巡检任务指令，
自动完成"地图切换 → 位姿初始化 → 脱桩 → 逐工位走行 → 机械臂轨迹拍照 → 精扫图像采集 → 回充"的
全自动轮对质检流程，并将采集数据、时间点与报警信息实时上报 WEB 工作站与 EMIS 系统。

## 2. 软件架构（三层架构）

### 2.1 分层设计

| 层 | 组成 | 职责 |
|----|------|------|
| 界面层 | c_Robot_App_Widget（QMainWindow）+ Fr_Light/Map_View/Lidar_View（QWidget） | 实例化 UI 与所有业务线程；界面刷新与信号槽桥接 |
| 业务层 | Magic/IO/CGXi/Voice/Lczh/Work/Server_Remote/MySql/Emis（8 类，父类 c_Object） | 组合通讯层对象，完成协议解析与业务逻辑 |
| 通讯层 | HTTP_Client/ModeBusTCP_Client/ModeBusRTU_Master/Scan_Client/Robot_Server（5 类，父类 c_Object） | 仅协议数据收发，零解析零业务耦合 |

- 公共父类 c_Object：提供非阻塞延时 msleep、类型转换模板接口与统一状态信号
- 数据存储：c_Variable 单例（Meyers 模式）承载全部协议解析数据，各线程经 getInstance().g_Xxx 直接访问
- 线程层级：通讯层线程在业务层 Init 内创建；业务层线程在界面层构造函数错峰创建（100~750ms 分时）

## 3. 核心流程设计

### 3.1 自动巡检流程

```
WEB 下发 START_INSPECTION（校验 10 字段+禁字符+startTime 12 位）
→ 任务状态门控 → 解析写入 g_Work_DB
→ 工序链：机械臂开机 → 刷新地图列表 → 加载地图 → 刷新导航点
→ 动态初始化 P001（充电位置=初始化点）→ 脱桩 → 机械臂使能
→ 配方加载（车型→轮对类型→点:[轨迹] 三层查找）
→ 巡检走行：单工位按 posId 过滤；双工位共用线逐点归属执行
   （共用点 P1.1/P4.1 先 1 号工位轨迹后 2 号工位轨迹；每点采集前切换采集上下文 12 项）
→ 收尾：回充 P0 → 完成上报
```

### 3.2 导航定位失败判定（防碰撞）

- 官方 is_finished=true 语义含"完成/无法到达/取消"，不可直接判成功
- 定位正常 = 任务完成 且 目标点在导航点列表 且 坐标距离 ≤1.5m 且 角度偏差 ≤10°（环形差）
- 其他一律定位异常 → 终止任务 + 语音报警（PA022）——防止机械臂在错误工位动作碰撞

### 3.3 图像采集协议

- START&{送修单位}&{年月日}&{时分}&{车型轮对类型}&{任务编号}
- CHANGE&GAIN&{增益}（与 PHOTO 间隔 50ms 非阻塞延时）
- PHOTO&{车型轮对类型}&T1-{年月日}-{车型轮对类型}-{车轴型号轮对号}-{轴号}-{工位号}-{轨迹索引}-{一级部件}-{二级部件}-{巡检点}（11 段文件名）
- 反馈：PHOTO&COMPLETE → 回机械臂 <COMPLETE><T1>!
- 结束：机械臂 PHOTO&FINISH! → 采集软件 PHOTO&FINISH
- 所有指令无空格（remove 空白防御）；PHOTO 超时 6s 自动重发（3 次上限）

## 4. 关键机制设计

### 4.1 三色灯与语音联动

- 红=错误（急停/断连/相机故障/机械臂错误/任务失败）+ 对应语音报警
- 黄=运动（巡检中/机械臂运行）+ 提示语音
- 绿=静止无错 + 停止语音播报
- 设备恢复自动切回正常状态（状态驱动+档位防抖+恢复日志）
- 未连接不报警（"曾经就绪"原则）

### 4.2 并发与锁协议

- QReadWriteLock g_lock：读侧 QReadLocker 快照、写侧 QWriteLocker
- 锁非递归：函数级锁内禁止再取锁（C1 教训）；AA2 锁外重解码+锁内赋值
- 跨线程交互一律信号槽（queued）+ invokeMethod；GUI 线程禁止阻塞

### 4.3 日志与配置

- 中心日志 Debug_DB/软件操作日志_yyyyMMdd.log（等级过滤/脱敏/限流/保留策略防磁盘占满）
- 通讯层零收发日志（失败 ERROR 与连接事件除外）
- 配置 System_DB/Communicate_DB.json（132 键）

## 5. 界面设计

- 主窗口 stackedWidget 8 页：机械臂/关节/ TCP 状态/机器人状态/精扫相机/IO/巡检任务/底盘
- 巡检任务页：任务信息（21 项实时显示）、子系统状态灯（机械臂/底盘/相机/WEB）、
  工作流状态、WEB 服务器、报警列表、一键巡检（Axis_Position.json 编辑弹窗）
- 状态栏：系统时间/刷新帧率/机械臂帧率/相机帧率

## 6. 数据库设计

- tbl_robot_detection_time（inspection_task_num/image/collection_time）——采集时间与图片记录
- 写入队列+指数退避重试（100ms→5s 封顶）；1062 Duplicate entry 幂等视为成功

## 7. 安全与可靠性

- 指令字段禁空格/&/- 校验；机械臂消息段白名单（字母/数字/点）校验
- 单实例守卫；关闭确认+线程回收（quit→wait→terminate 兜底）
- HTTP Token 定时刷新+401 自动重登；断线指数退避重连
- 导航定位双阈值防碰撞；机械臂轨迹执行前设备连接快查
