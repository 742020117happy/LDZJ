轮对质检机器人控制平台 V1.0 — WEB 端调用方法说明

 

版本：V1.3　日期：2026-11-04（V1.3：三字段原样回显定稿——反馈的 Cmd_Name/Value/Checksum 与接收指令完全一致；生命周期通知回显发起指令字段）

服务端：工控机 Robot_App（TCP Server 192.168.6.35:520，配置键 Local_IP/Server_Port）

报文格式：JSON（UTF-8），粘包按花括号深度解析；除 Read_Ready 外所有指令需携带 Checksum（幂等去重）

 

一、通用约定

 

  • 指令 JSON（**至少含 3 字段**）：`{ "Cmd_Name": "指令名", "Value": true, "Checksum": "唯一校验码", ...业务字段 }`

  • Checksum：每次下发唯一（如时间戳字符串）；同一 Checksum 重复下发将被忽略（幂等去重，防止重复执行）

  • 响应 JSON（**至少含 5 字段**）：`{ "Cmd_Name": "...", "Value": true|false, "Checksum": "回显", "Status": "Success|Error", "Message": "..." }`（旧 Result/Reason/小写 status 格式已废除）

  • **Checksum 回显（2026-11-04 定稿）**：所有控制指令的响应 JSON 均包含 `"Checksum"` 字段，回显本次请求携带的 Checksum（供 WEB 端匹配请求-响应）：

  • 正常响应 / 状态门控拒绝 / 重复指令 / 未知命令 → 均回显本次请求 Checksum

  • 缺 Checksum 的指令 → 返回错误响应（不含 Checksum 字段）：

`{ "Cmd_Name": "XXX", "Result": "Error", "Reason": "缺少 Checksum" }`

  • Read_Ready 查询可携带 Checksum（可选）——携带则响应回显，不携带则响应不含该字段

  • 查询频率：Read_Ready 建议 500ms 一次；查询类指令不产生服务端日志

 

二、指令清单

 

指令 功能 允许状态 说明
START_INSPECTION 下发巡检任务 空闲/就绪/完成/错误 携带 tasks 数组（见 §三）
Pause 暂停任务 采集中 暂停机械臂+底盘任务
Resume 恢复任务 暂停中 恢复机械臂+底盘任务
Cancel_Task 取消任务 任意状态 立即停止退出：停机械臂+停底盘+门控复位（2026-11-04 定稿）
Emergency_Stop 软急停 任意 停机械臂（89=3）
Return_Home 回原点 空闲/就绪/完成/错误 机械臂回零位
Read_Ready 状态查询 任意 Checksum 可选；响应全中文 Key+回显 Checksum（如携带，见 §四）

五、调用示例（C#/Java/任意 TCP 客户端伪码）

 

// 1. 下发巡检任务

send(json({

"Cmd_Name": "START_INSPECTION",

"Value": true,

"Checksum": "20261104120000task001",

"wheelsetCount": 1,

"tasks": [ { ...单工位任务字段... } ]

}));

 

// 2. 查询状态（500ms 轮询，Checksum 可选携带）

send(json({ "Cmd_Name": "Read_Ready", "Value": true, "Checksum": "1792843238257" }));

 

// 3. 暂停 / 恢复 / 取消

send(json({ "Cmd_Name": "Pause", "Value": true, "Checksum": "..." }));

send(json({ "Cmd_Name": "Resume", "Value": true, "Checksum": "..." }));

send(json({ "Cmd_Name": "Cancel_Task", "Value": true, "Checksum": "..." })); // 任意状态可用，立即停止

 

// 4. 软急停 / 回原点

send(json({ "Cmd_Name": "Emergency_Stop", "Value": true, "Checksum": "..." }));

send(json({ "Cmd_Name": "Return_Home", "Value": true, "Checksum": "..." }));

七、注意事项

 

1. Read_Ready 的 Checksum 可选（建议携带便于响应匹配）；其余指令必须带 Checksum；重复 Checksum 会被幂等忽略

2. Cancel_Task 在任意状态（含采集中/暂停中）均有效——取消后机器人立即停止并退出任务（2026-11-04 定稿）

3. 状态查询响应 Key 为全中文（2026-10-28 定稿），旧英文 Key 已废除

4. Read_Ready 以 500ms 频率查询不会产生服务端日志（日志抑制）

5. TCP 断线后服务端自动清理客户端并监听新连接

6. **反馈三字段原样回显**（2026-11-04 定稿）：Cmd_Name/Value/Checksum 与接收指令完全一致；生命周期通知（ACCEPTED/READY/COMPLETED/ERROR）回显发起指令 START_INSPECTION 的三字段；WEB 端可按 Cmd_Name+Checksum 匹配请求与响应（含异步通知）

2. Cancel_Task 在任意状态（含采集中/暂停中）均有效——取消后机器人立即停止并退出任务（2026-11-04 定稿）
